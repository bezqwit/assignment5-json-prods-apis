NASA Astronomy picture of the day

What?: The NASA Astronomy Picture of the Day API returns different astronomy images every day with a description written by an astronomer.

Why I selected it: It is free, returns JSON, and I actually used this API for a CS assignment in high school so it's familiar.

Cite: https://api.nasa.gov/

Parameters: It only needs an api_key which I got from the api.nasa.gov. This is what allows my request for the info.

helpful?: A school could use this to show students astronomy images every day. I used it in school when I took a CS class that collaborated with the astronomy class to showcase the use of the API.
